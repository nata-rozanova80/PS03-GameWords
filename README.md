# Игра "Угадай слово" с использованием Python

Этот скрипт представляет собой игру, в которой пользователь должен угадать английское слово по его определению, переведённому на русский язык. В процессе игры используется сайт для получения случайных английских слов и их определений, а также библиотека для перевода текста.

## Зависимости

Для работы скрипта вам нужно установить следующие библиотеки:

1. **requests** — для выполнения HTTP-запросов и получения данных с сайта.
2. **BeautifulSoup** — для парсинга HTML и извлечения информации со страницы.
3. **googletrans** — для перевода текста с английского на русский.

### Установка зависимостей

1. Установите Python 3.x с официального сайта: https://www.python.org/downloads/
2. Установите необходимые библиотеки с помощью pip:
    ```bash
    pip install requests beautifulsoup4 googletrans==4.0.0-rc1
    ```

## Как использовать

1. Запустите скрипт:
    ```bash
    python script_name.py
    ```
2. После запуска скрипта вам будет показано описание случайного английского слова на русском языке. Ваша задача — угадать это слово.
3. После ввода вашего ответа, программа сообщит, правильно ли вы угадали слово.
4. Если вы хотите сыграть ещё раз, просто введите "д". Если хотите выйти — введите "н".

## Примечания

- Сайт, с которого извлекаются случайные слова, может иногда менять свою структуру, что может вызвать ошибку в работе скрипта.
- Перевод используется через Google Translate, поэтому качество перевода зависит от точности работы этого сервиса.

## Автор

Этот проект был создан для тренировки и улучшения навыков работы с Python и библиотеками для веб-запросов и перевода текста.
